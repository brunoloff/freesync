FreeSync

Keep local folders and Google Drive in sync.

FreeSync is a desktop file synchronization application being developed for Linux, Windows and macOS. Its intended features include watching local file changes, detecting changes on Google Drive, transferring files and resolving conflicts.

FreeSync has a usable Linux desktop preview with native Google OAuth, automatic two-way sync, recoverable transfers and a Tauri settings interface. Its adoption workflow compares existing files read-only and supports reviewed subfolder activation with backups. Phases 1–7 passed their acceptance checks, including a three-hour native-desktop run; full real-tree adoption validation is in progress. Large-tree performance, Windows/macOS validation and installers remain later phases.

Connecting Google Drive

You authorize FreeSync with Google in your browser. FreeSync needs permission to see, edit, create and delete Drive files so it can work with existing folders and files. That Google permission covers the whole account; folder restrictions are enforced by FreeSync itself. Automated development tests are limited to a designated test folder.

FreeSync runs locally. It has no central service for receiving your Drive files or account credentials. Refresh tokens are saved in the operating system credential store.

Project information

This is a personal development project maintained by Bruno Loff. It is experimental software and is not affiliated with Google. Follow development in the public GitHub repository.
